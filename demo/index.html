Under the Hood

The LangGraph workflow.

Six nodes. Conditional edges. Clean state machine.



# graph/workflow.py — the complete routing logic from langgraph.graph import StateGraph, END, START def _route_after_review(state) -> str: if state["review_approved"]: return "executor" if state["code_iteration"] >= MAX_CODE_ITERATIONS: return "executor" return "coder" # loop back for revision def _route_after_execution(state) -> str: if state["execution_success"]: return END if state["debug_attempts"] >= MAX_DEBUG_ATTEMPTS: return END return "debugger" # auto-fix and retry graph = StateGraph(AgentState) graph.add_node("orchestrator", orchestrate) # 🎯 graph.add_node("planner", plan) # 📋 graph.add_node("coder", code) # 💻 + Tavily graph.add_node("reviewer", review) # 🔍 graph.add_node("executor", execute) # ⚡ subprocess graph.add_node("debugger", debug) # 🐛 graph.add_edge(START, "orchestrator") graph.add_edge("orchestrator", "planner") graph.add_edge("planner", "coder") graph.add_edge("coder", "reviewer") graph.add_conditional_edges("reviewer", _route_after_review) graph.add_conditional_edges("executor", _route_after_execution) graph.add_edge("debugger", "coder") # debug → recode → review → execute
Features

Everything you need.



🧠
6 Specialized Agents
Each agent has one job. Separation of concerns built into the architecture.
🌐
Tavily Web Search
Coder searches documentation in real-time before writing. Always current API usage.
🔁
Auto Review Loop
Reviewer scores 1–10. Code loops back for revision until quality ≥ 7. Max 3 passes.
🐛
Auto Debug Loop
Runtime errors trigger the Debugger automatically. Root-cause analysis + fix applied.
🔬
LangSmith Traced
Every LLM call, token count, latency, and tool use logged to smith.langchain.com.
🌊
Flowise Visual
Full 8-node pipeline visualized on Flowise Cloud canvas. Shareable for demos.
🛡️
Isolated Execution
Code runs in a subprocess with timeout enforcement. Main process stays safe.
⚡
Groq Inference
Llama 3.3 70B on Groq hardware. Sub-second LLM responses. 3x retry on rate limits.
🌍
7+ Languages
Python (with execution), JavaScript, TypeScript, Java, C++, Rust, Go.
